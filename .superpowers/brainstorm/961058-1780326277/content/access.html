How should the app connect to the backend?

The React Native app needs to reach the ArtCRM API on your VPS (82.165.32.162:8084)

A

Direct to VPS over the internet

App talks to https://crm.christopherrehm.de — HTTPS, login required. Works anywhere, no VPN.

Pros

  • Works on any network
  • Simple setup

Cons

  • API must be publicly exposed
  • Need SSL on the VPS
B

VPN only

App connects through a VPN (e.g. WireGuard on the VPS) — API stays private.

Pros

  • API never exposed publicly
  • More secure

Cons

  • Must enable VPN to use app
  • Extra setup
